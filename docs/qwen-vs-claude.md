# qwen3.5:9b 와 Claude Opus 5.5 비교 기록 (2026-11-25)

같은 영상, 같은 요청, 같은 프롬프트로 에이전트·비전 모델만 바꿔 돌린 결과다.
요청마다 Claude 는 한 번, qwen 은 한두 번씩만 돌렸으므로 경향을 보는 용도이고 통계는 아니다.

- 정답 구간은 받아쓰기와 노래 감지 결과를 사람이 읽고 정했다.
- 정답 구간은 두 모델 모두 매번 찾았다. 차이는 오답 후보에서 났다: qwen 은 다섯 번 중 두 번 오답을 섞었고, Claude 는 세 번 모두 정답 구간만 냈다.
- Claude 가 2~4배 빨랐다. qwen 은 GPU 한 장에서 에이전트 4개와 비전 호출이 번갈아 돈다.

## 읽을 때 주의할 점

- 실행 횟수가 적다. qwen 은 같은 요청도 실행마다 결과가 달랐다 (위 표의 `/` 앞뒤).
- Claude 실행 중에는 다른 Ollama 테스트가 같은 GPU 에서 돌고 있었다. Claude 쪽은 받아쓰기와 노래 감지만 GPU 를 쓰므로 영향은 작다.
- 이 비교 전에 고친 것들(Whisper 타임스탬프, 500 처리, hotwords 끔, 노래 판정, 조각 경계 반올림, 프롬프트)은 두 모델에 똑같이 적용된 상태다.
- qwen 이 프롬프트 수정 전에 보인 문제(조각 일부만 제출, 구간을 윈도우별로 쪼개 제출 등)는 이 표에 없다.
